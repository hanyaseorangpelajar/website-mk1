## About

My personal portfolio website from 2023, built as a static site with a homepage, an about section, and a project showcase.

## Features

- Personal homepage with profile photo and caption
- About section
- Project showcase
- Header and navigation bar

## Tech Stack

- HTML
- CSS
- JavaScript

## Prerequisites

- A modern web browser
- A local web server, optional, for serving the folder locally

## Installation

```
git clone https://github.com/hanyaseorangpelajar/website-mk1.git
cd website-mk1
```

## Usage

Open `index.html` in a browser, or serve the folder with a local web server.

## Project Structure

```
website-mk1/
├── CNAME         # GitHub Pages custom domain
├── LICENSE
├── README.md
├── index.html    # Main page
├── main.js       # Page scripts
├── style.css     # Page styles
└── img/          # Images
```

## Deployment

Deployed on GitHub Pages, with a custom domain set in the CNAME file.
